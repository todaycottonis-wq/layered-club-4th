# 신청 데이터·방문 통계를 구글 시트로 받기

## 처음 설정할 때 (5분)

1. 새 구글 시트를 만들어요. (이름 예: `레클 4기 신청`)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script.gs` 내용을 통째로 붙여넣어요.
3. 코드 위쪽 설정 두 가지를 채워요.
   - `ADMIN_KEY = '...'` : **관리자 페이지 비밀번호**. 길고 어려운 값으로 정해요. (비워두면 관리자 페이지가 꺼져요)
   - `NOTIFY_EMAIL = '...'` : 새 신청이 올 때 알림 메일을 받을 주소. (필요 없으면 비워둬요)
4. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포하고 권한을 승인해요.
5. 나오는 **웹 앱 URL**(`…/exec`)을 `config/endpoint.txt`에 넣어요. (이미 들어 있으면 그대로)

## 코드를 수정한 뒤 다시 배포할 때 (URL이 바뀌지 않게)

Apps Script에서 **배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포**.
"새 배포"로 만들면 URL이 바뀌어요. 꼭 기존 배포를 편집해서 새 버전으로 올려요.

## 시트에 생기는 탭

- **신청**: 신청서가 한 줄씩 쌓여요. `입금 확인` 열에 O를 적으면 관리자 페이지에 "입금 확인"으로 반영돼요.
- **이벤트**: 방문·이탈 기록이에요. 방문자 ID, 어떤 단계까지 갔는지만 들어 있고 이름·연락처는 없어요. 직접 건드리지 않아도 돼요.

## 관리자 페이지

- 주소: 배포 사이트 주소 뒤에 `/admin/` (예: `https://사이트주소/admin/`)
- 비밀번호: 위의 `ADMIN_KEY`
- 볼 수 있는 것: 방문자·페이지뷰, 일별 추이, 신청 퍼널, 신청을 시작했지만 완료하지 않은 방문자의 이탈 단계, 트랙 선택, 어디까지 읽었는지, 유입 경로·기기, 신청 목록(검색·입금 확인 전만 보기·CSV 내려받기).
- 검색 엔진에는 노출되지 않게 막아뒀지만, 주소와 비밀번호를 아는 사람은 신청자 연락처를 볼 수 있어요. 공유하지 마세요.
- 내 방문을 통계에서 빼려면 사이트 주소 끝에 `?notrack`을 붙여서 열어요.
- 채널별 유입을 보려면 공유 링크 뒤에 `?utm_source=instagram`처럼 붙여요.
