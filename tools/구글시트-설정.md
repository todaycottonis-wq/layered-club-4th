# 신청 데이터를 구글 시트로 받기 (5분)

1. 새 구글 시트를 만들어요. (이름 예: `레클 4기 신청`)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script.gs` 내용을 붙여넣어요.
   - 새 신청마다 알림 메일을 받으려면 `NOTIFY_EMAIL`에 본인 메일을 적어요.
3. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포를 누르고, 권한 승인을 해요.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해서 알려주세요.
   - 페이지 코드의 `CONFIG.endpoint`에 넣고 다시 배포하면 신청이 시트에 쌓여요.

## 시트에서 보는 법
- `신청` 탭에 한 줄씩 쌓여요: 접수시각, 구분(신규/기존), 기수, 트랙, 참가비, 성함, 이메일, 연락처, 신청 이유 등.
- 입금자명은 **성함/닉네임** 열과 비교해서 확인하고, **입금 확인** 열에 O 표시를 해두면 편해요.
